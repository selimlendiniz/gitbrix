# gitbrix

A fast, graph-first desktop Git client built with Tauri 2, Rust and React.

- Commit graph with lane layout computed in Rust and drawn on canvas
- Stage, unstage, discard, commit, amend
- Branches, remotes, tags, stashes; checkout, merge, rebase, cherry-pick, revert, reset
- Fetch, pull, push through the real `git` CLI (your hooks, credentials and ssh config apply)

See `PROGRESS.md` for how to run, test and what's done; `docs/PLAN.md` for the roadmap.
